# AI Usage Statement

This project used AI assistance during development and documentation preparation. The team will review and edit all AI-assisted content before final submission.

## Where AI Was Used

AI was used most heavily for:

- drafting project documents;
- organising report structure;
- preparing UML and ER diagram text;
- preparing test case descriptions;
- improving wording in the video script;
- generating first-draft explanations for member study notes.

AI was also used to help generate and review parts of the Java/JDBC implementation. The final code must be read, tested, and understood by the team members before submission and interview.

## Human Review

The team should manually check:

- whether the implemented features match the coursework requirement;
- whether the database schema and ER diagram are consistent;
- whether the code runs on the machines used for demonstration;
- whether each member can explain their assigned module;
- whether the final report honestly describes the actual work process.

## Important Note

The submitted report should not claim that AI was only used for documentation if AI also helped with code. A correct and safe statement is:

> AI tools were used to support documentation drafting, project organisation, and parts of code generation/review. The team reviewed, tested, and adapted the generated material before submission.

## Suggested Report Sentence

AI assistants were used during this project mainly to help draft documentation, organise report content, prepare diagram descriptions, and support parts of code generation and review. All AI-assisted materials were checked and edited by the team, and the team members prepared to explain the implemented database design, Java code, and system behaviour during the interview.
